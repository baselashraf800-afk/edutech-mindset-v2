# EduTech Mindset | عقلية التعليم والتكنولوجيا — Android v2.1.0

تطبيق **EduTech Mindset (عقلية التعليم والتكنولوجيا)** الرسمي للأندرويد بإدارة **الأستاذ باسل أشرف الفقعاوي** (`com.aistudio.edutechmindset.bfkqaz`) — الإصدار `v2.1.0` (`targetSdk 35`).

## أبرز مميزات الإصدار v2.1.0
- 🎬 **مشغّل فيديو المقدمة العمودي (`IntroVideoOverlay`)**: يعمل تلقائياً عند التشغيل بدون زر تخطي مع زر «🚀 ادخل التطبيق» بعد الانتهاء ودخول تلقائي بعد 3.5 ثوانٍ.
- 🔙 **نظام الرجوع للخلف ذو الـ 5 أولويات (`BackStackManager`)**: يغلق أولاً الأدوات العائمة، ثم شاشات أندرويد الداخلية، ثم نوافذ الموقع المنبثقة، ثم يتراجع في سجل التصفح متخطياً صفحات `about:blank` و`accounts.google.com`، وأخيراً تنبيه الضغط مرتين للخروج.
- 🎛️ **لوحة المساعد التعليمي الذكية (`EduTechHubSheet`)**: منظمة في 4 تبويبات (الدرس، التركيز، الأدوات، المكتبة) وتضم 48 ميزة وأداة تعليمية متكاملة.
- 🧮 **أدوات الدراسة العائمة (`StudyToolsOverlay`)**: السبورة السريعة للرسم والكتابة، الحاسبة العلمية العائمة، ومؤقت التركيز (Pomodoro) وساعة الامتحان.
- 🧩 **ودجت الشاشة الرئيسية (`EduTechWidgetProvider`)** و**منبه المذاكرة اليومي (`StudyReminderReceiver`)** و**اختصارات أيقونة التطبيق (`shortcuts.xml`)**.
- 🌐 **الفقاعة العائمة فوق التطبيقات (`OverlayAssistantService`)** مع القص الدائري (`ViewOutlineProvider.setOval`) وإغلاق نافذة تسجيل الدخول بحساب Google تلقائياً (`closeAuthPopup()`).
