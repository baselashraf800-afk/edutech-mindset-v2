# دليل الإصدار 249 — EduTech Mindset

## أبرز الإصلاحات:
1. **فصل «المعلم الخصوصي الذكي» عن «مساعد المعلم الذكي»:** يفتح زر «المعلم الخصوصي الذكي» في مسار الطالب نافذة المحادثة التفاعلية `#eduAsst` مباشرة، بينما انتقل `#aiStudio` (مساعد المعلم الذكي لتحضير الدروس والاختبارات) إلى مسار المعلم.
2. **تفعيل زر «🎓 الدورات» في الشريط السفلي 100%:** تحميل تلقائي لقسم الدورات التدريبية (`#coursesSection`) وتمرير مباشر فوري عند الضغط على «الدورات».
3. **طبقة صوت سحابية عربية رابعة مضمونة + فاحص مزوّدي الصوت الفوري:** إضافة بديل سحابي عربي MP3 مضمون في `_worker.js`، وزر «🔍 فحص حالة مزوّدي الصوت الآن» في لوحة الإدارة لعرض حالة ElevenLabs وGemini وEdge مباشرة.
