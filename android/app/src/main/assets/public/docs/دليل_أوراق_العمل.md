# مولّد أوراق العمل والاختبارات

1) **انشر قواعد Firestore المحدّثة** (ملف firestore.rules): فيها قاعدة مجموعة `worksheets`. أوراق كل معلم خاصة به فقط.
2) القسم يظهر بعد «مولّد العروض»، ويمكن إخفاؤه أو نقله من تخصيص الموقع ← الأقسام.
3) الاستخدام: اكتب الموضوع أو صوّر صفحة الدرس ← اختر النوع (ورقة عمل / اختبار) والمستوى وأنواع الأسئلة ← «ولّد الأسئلة». عدّل أي سؤال، ثم معاينة أو PDF.
4) PDF الطالب بمساحات الإجابة وبيانات الطالب، وPDF المعلم بمفتاح الإجابات. خيار النسختين أ وب يولّد نسخة مكافئة بأسئلة مختلفة.
5) اسم المدرسة واسم المعلم والزمن تُحفظ في متصفحك وتظهر في ترويسة كل ورقة.
6) الحفظ يتطلب تسجيل الدخول بحساب Google.
