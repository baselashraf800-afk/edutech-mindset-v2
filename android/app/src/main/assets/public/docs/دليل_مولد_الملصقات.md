# مولّد ملصقات الإعلان

الإدارة ← تبويب **«مولّد الملصقات»**.

1. اختر **الثيمة** (ملكي، ذهبي، قرمزي، زمردي، بنفسجي، فاتح) و**المقاس**: طولي 4:5 (واتساب/فيسبوك)، مربع، ستوري 9:16، أو عريض 16:9 (مناسب لإعلانات واجهة الموقع).
2. اكتب الشارة (مثل «ورشة تدريبية»)، والعنوان، والتفاصيل، وحتى ثلاثة أسطر معلومات (📅 الموعد، 📍 المكان، 📞 التواصل)، والتذييل. المعاينة تتحدث فوراً، ويُحفظ آخر ما كتبت.
3. الأزرار:
   - **⬇ تنزيل PNG** لإرسال الملصق على واتساب أو نشره في أي مكان.
   - **↗ مشاركة** تفتح مشاركة الهاتف مباشرة (حيث يدعمها المتصفح).
   - **📢 انشر كإعلان بالواجهة** يضيف الملصق شريحة جديدة في إعلانات الصفحة الرئيسية (يُرفع إلى R2 إن كان مفعّلاً، وإلا يُحفظ مضغوطاً في قاعدة البيانات؛ يُفضّل المقاس «عريض»). ويمكنك لاحقاً إدارته أو حذفه من «إعلانات الواجهة».

الخط المستخدم Alexandria (من الموقع نفسه) والشعار يُوضع تلقائياً ويمكن إخفاؤه.
