# الشريط العاجل

شريط متحرك أعلى كل صفحات الموقع، تظهر فيه رسائلك لكل الزوار فور الحفظ.

## الإضافة والتعديل
الإدارة ← تبويب «الشريط العاجل»:
- **+ عاجل / + تنويه / + مناسبة:** يضيف رسالة بالنوع المطلوب (شارة حمراء/زرقاء/ذهبية).
- لكل رسالة: النص، **رابط اختياري** (https://… أو رابط داخلي مثل #learn)، **تاريخ انتهاء اختياري** تختفي بعده تلقائياً، ومربع «ظاهرة» لإخفائها مؤقتاً، وأزرار ترتيب وحذف.
- «تفعيل الشريط» لإيقافه كله، وسرعة الحركة (بطيئة/عادية/سريعة)، ثم **«حفظ الشريط»**.

## ما يراه الزائر
- النص يتحرك ويتوقف عند اللمس أو الوقوف عليه، وفيه أزرار: 🔊 استماع (قراءة صوتية بالعربية)، ⏸ إيقاف الحركة، ✕ إخفاء لهذه الجلسة.
- الرسالة ذات الرابط يمكن الضغط عليها.
- من أوقف الحركات في جهازه يرى النص بدون تحريك.
- يُحفظ الشريط على الجهاز فيظهر فوراً حتى مع ضعف الاتصال.

لا يحتاج الشريط قواعد Firestore جديدة (يُخزَّن في site/ticker ضمن قاعدة site الحالية).
