# دليل الإصدار 218 — إصلاح الإعلانات والدورات وتوحيد الواجهة المفتوحة

## أبرز ما تم إصلاحه وتطويره
| المحور | التعديل المنفّذ |
|---|---|
| إظهار الدورات والأقسام | إزالة `coursesSection` و`homeAds` و`homeVideos` و`social` و`about` من الإخفاء القسري في `master-hierarchy.js`، وتثبيت قسم الدورات مباشرة بعد الاختصارات السريعة مع عرض بطاقات معاينة للدورات في الرئيسية |
| تداخل زر المساعد الذكي | خفض `z-index` لأيقونة `#eduAsstOrb` وإخفاؤها تلقائياً عند فتح أي نافذة منبثقة (`html.modal-open` / `body.edu-any-modal-open`)، ونقل إشعار `#toast` للأعلى عند فتح النوافذ حتى لا يغطي أزرار الحفظ |
| إصلاح حفظ الإعلانات في السحابة | إضافة تنبيه واضح وزر دخول Google فوري عند الفتح برمز PIN فقط، وفحص حجم الصور قبل الإرسال لـ Firestore (تحت حد 1MB) مع ضغط أدق ورسائل خطأ واضحة تشرح السبب الحقيقي |
| ترتيب الرئيسية المفتوحة | اعتماد التسلسل الموحّد: الهيدر ← الإعلانات ← الاختصارات السريعة (4 بطاقات) ← بوابة الدورات ← الأقسام التعليمية والمكتبة والاستوديوهات ← الفيديوهات ← حسابات التواصل ومن نحن |
| الشريط السفلي ولوحة الإدارة | ضبط الشريط السفلي للجوال لـ 5 وجهات رئيسية (الرئيسية، الدورات، الأدوات، المكتبة، حسابي)، وإضافة تبويب «الدورات والتسجيل» داخل مركز تطوير وتخصيص الموقع |
| تنظيف CSS وأداة البناء | إصلاح محددات الهيدر في `css/v171-polish.css`، ودعم `terser` تلقائياً في `tools/build.sh` بجانب `esbuild` |
