# دليل الوسائط والتخصيص — EduTech Mindset

## ما الجديد في هذه النسخة
| الميزة | أين تجدها |
|---|---|
| المراحل ← الصفوف ← المواد ← الفيديوهات | قسم «المراحل الدراسية» في الصفحة (يظهر لك أزرار التعديل عند دخول الإدارة) |
| القوائم العلوية (مع قوائم فرعية) | زر **تخصيص الموقع** ← القوائم |
| الإعلانات (نص + عدة صور تتبدل) | تخصيص الموقع ← الإعلانات |
| فيديوهات الأعلى (تعمل عند المرور) | تخصيص الموقع ← فيديوهات الأعلى |
| الصوت المشترك + شاشة الدخول | تخصيص الموقع ← الصوت |
| الشعار واسم الموقع وعناوين الغلاف و«من نحن» | تخصيص الموقع ← الهوية والنصوص |
| إظهار/إخفاء/ترتيب أقسام الصفحة | تخصيص الموقع ← الأقسام |
| الألوان والخطوط والروابط والترحيب والمشرفون والمحركات الذكية | تخصيص الموقع ← إعدادات أخرى |

زر «تخصيص الموقع» (برتقالي أسفل الشاشة) يظهر **للإدارة فقط** بعد تسجيل الدخول وإدخال رمز الإدارة.

## تفعيل رفع الملفات (مرة واحدة) — Cloudflare R2
بدون هذه الخطوة يعمل كل شيء، لكن رفع الصوت/الفيديو/الصور من الجهاز لن يظهر (تبقى روابط يوتيوب وروابط الصوت المباشرة تعمل).

1. ادخل https://dash.cloudflare.com ← **R2 Object Storage** ← **Create bucket** ← الاسم: `edutech-media` (الخطة المجانية تكفي: 10 جيجا).
   - قد يطلب Cloudflare إضافة بطاقة دفع للتفعيل فقط؛ الاستخدام ضمن الحد المجاني لا يُحاسَب.
2. ارجع إلى **Workers & Pages** ← مشروع `edutech-mindset` ← **Settings** ← **Bindings** (أو Functions) ← **Add** ← **R2 bucket**.
   - Variable name: **`MEDIA`** (بالأحرف الكبيرة تماماً)
   - R2 bucket: `edutech-media`
   - احفظ.
3. أعد نشر الموقع (ارفع ملف ZIP من جديد) ليأخذ الربط.
4. افتح الموقع ← تخصيص الموقع ← الصوت: يجب أن يختفي التنبيه الأصفر ويعمل زر «رفع ملفات صوتية».

حدود الرفع: الصوت 60 ميغابايت للملف، الفيديو 95 ميغابايت، الصور 8 ميغابايت. للفيديوهات الطويلة استخدم يوتيوب.
الرفع والحذف **للإدارة فقط** (يتحقق الخادم من حساب Google). أما المشاهدة فلكل الزوار.

## الصوت التلقائي — ما الممكن؟
المتصفحات تمنع أي صوت قبل أن يتفاعل الزائر مع الصفحة. لذلك:
- **شاشة الدخول** (الافتراضي): الزائر يضغط «ادخل الموقع» فيبدأ الصوت فوراً. هذا الأضمن.
- **أول نقرة/لمسة**: يبدأ الصوت عند أول نقرة أو ضغطة مفتاح في أي مكان (تحريك الماوس أو التمرير وحدهما لا يكفيان).
- يمكن للزائر كتم الصوت أو إيقافه من المشغّل في أي وقت.

## قواعد Firestore
لا تغيير مطلوب على `firestore.rules` الحالي: المحتوى الجديد يُحفظ في `site/home` و`site/audio` و`site/curriculum` و`site/slide-*` وكلها قراءة للجميع وكتابة للإدارة.
