# دليل الإصدار 246 — EduTech Mindset

## أبرز التطويرات والإصلاحات:
1. **ترقية سلسلة الأصوات العربية الفصحى (`_worker.js` + `tts-client.js`):** ترتيب صارم يبدأ بـ **ElevenLabs (`eleven_multilingual_v2` للأصالة والفخامة ← `eleven_flash_v2_5`)** ثم **Gemini 2.5 Flash TTS (بنبرة فصحى تعليمية ملهمة)** ثم **Edge Neural (`Zariyah` / `Hamed`)** ثم المحلي عند انقطاع الشبكة.
2. **إعادة بناء واجهة المساعد الذكي (`assistant.js`):** ترويسة مضغوطة في سطر واحد بدون شارة `v153` أو نصوص ملتفة، وتصميم شريط كتابة عصري من صفّين (`#eaTxt` بعرض 100% + شريط أدوات مرتّب أسفله) مع استغلال كامل مساحة الشاشة للمحادثة.
3. **موشن جرافيك مرئي ومبهج 60fps:** خلفية شفق متموجة واضحة وأيقونات تعليمية طافية وهالات إضاءة ناعمة على البطاقات.
4. **تنظيف `index.html`:** إزالة رابط Font Awesome المكرر وتحديث كاش `sw.js`.
