# دليل الإصدار 259 — EduTech Mindset

## أبرز التطويرات والدمج الكامل:
1. **استعادة وتوحيد المحركات الذكية الـ 12 الكاملة (`ai-admin.js` + `ai.js` + `_worker.js`):** Gemini، OpenAI، Claude، DeepSeek + الـ 6 الجديدة (**OpenRouter، Groq، Mistral، Cerebras، xAI، Hugging Face**) + Meta + المجاني، مع تثبيت قسم مفاتيح الصوت السحابي (**ElevenLabs** و**Cartesia**) وفاحص الصوت في أعلى تبويب «🤖 المحركات الذكية».
2. **تطوير لوحة الإدارة الموحّدة أسفل الموقع (`#adminDevFooterHub`):** تخصيص بطاقة «🎵 الموسيقى والأصوات الفصحى» (توقيت التشغيل ومستوى الصوت ورابط MP3 مخصص)، بطاقة «🔑 المحركات الذكية الـ 12»، زر «📢 الشريط العاجل»، زر «📱 رابط APK»، وشارة **`v259`** الخاصة بالإدارة فقط.
3. **خانة العمر (`enrAge`)** مفعّلة في نموذج التسجيل بالدورات وتظهر في بيانات المتدرب.
4. **ضمان وصول آخر نسخة (`v259`) تلقائياً لكل المستخدمين** عبر Network-First في `sw.js` و`max-age=0, must-revalidate` في `_headers` و`controllerchange` auto-reload في `pwa.js`.
