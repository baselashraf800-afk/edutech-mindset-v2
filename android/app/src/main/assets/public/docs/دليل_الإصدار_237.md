# دليل الإصدار 237 — توحيد كتبك المرفوعة بلا تعارض + تحكم الإدارة بمصدر الأصوات الفصحى

## أبرز ما تم إنجازه في الإصدار 237
| المحور | التحديث المنفّذ |
|---|---|
| إلغاء تعارض الكتب المرفوعة مع الافتراضية | دمج كتبك المرفوعة مباشرة داخل البطاقة العلوية الواحدة في تبويب «📖 الكتاب» (بأولوية مطلقة لكتبك مع أزرار التعديل والحذف للإدارة)، وإلغاء البطاقة السفلية والأزرار الصفراء المكررة |
| تحكم الإدارة الكامل بمصدر الأصوات (`🔊 إعدادات الأصوات`) | إضافة تبويب جديد في مركز التطوير محفوظ سحابياً في `site/voice_policy` يتيح للإدارة التبديل بين: **🌐 هجين ذكي**، **☁️ السحابة فقط (ElevenLabs/Gemini/Edge)**، أو **📱 أصوات الموقع المدمجة فقط (عربي فصيح فوري بلا إنترنت وبلا استهلاك رصيد)** مع ضبط السرعة وتجربة الصوت الذكوري والأنثوي مباشرة |
