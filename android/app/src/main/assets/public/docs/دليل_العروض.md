# مولّد العروض التقديمية

1) **انشر قواعد Firestore الجديدة (مطلوب مرة واحدة):** افتح Firebase Console ← Firestore ← Rules، والصق محتوى ملف `firestore.rules` كاملاً ثم Publish.
   بدونها يعمل التوليد والعرض لكن الحفظ ورابط الطلاب يعطيان رسالة "لا صلاحية".
2) القسم يظهر في الصفحة الرئيسية تحت «أدوات المعلم» باسم «مولّد العروض التقديمية»، ويمكن إخفاؤه أو نقله من: تخصيص الموقع ← الأقسام.
3) رابط الطلاب: `https://موقعك/?p=رقم_العرض` ويفتح العرض مباشرة بدون تسجيل دخول.
4) الحفظ يتطلب تسجيل الدخول بحساب Google. كل معلم يرى عروضه فقط.

5) **التصدير:** زر PDF يفتح نافذة الطباعة (اختر "حفظ كملف PDF"). زر PPTX يحمّل مكتبة PptxGenJS من cdnjs عند الضغط، فيحتاج إنترنت. أسئلة الاختيار تظهر في PowerPoint بلا إجابة، والإجابات في ملاحظات الشريحة وفي شريحة "مفتاح الإجابات" الأخيرة.

6) **التصويت السريع:** شريحة نوع «تصويت سريع» يصوّت عليها الطلاب من رابط العرض (صوت واحد لكل جهاز)، وتظهر النتائج للمعلم مباشرة أثناء العرض، مع زر «تصفير». يلزم حفظ العرض أولاً، ويلزم نشر ملف firestore.rules المحدّث (يحتوي قاعدة pollVotes الجديدة).

7) **صور الشرائح:** في محرر أي شريحة (غلاف، نقاط، خلاصة) زر «صورة الشريحة»: تصوير بالكاميرا أو اختيار من الجوال أو رابط https. تُضغط الصورة تلقائياً (نحو 100-170 كيلوبايت) وتُحفظ داخل العرض نفسه، وحد مجموع صور العرض الواحد نحو 700 كيلوبايت (4-6 صور). الغلاف يقبل صورة بجانب العنوان أو خلفية. تظهر في العرض وPDF وPPTX (الصور بالرابط تُدرج في PPTX فقط إن سمح موقع الصورة بذلك).
