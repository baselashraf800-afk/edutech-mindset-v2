# خطة التطبيق والتطوير الشامل — EduTech Mindset (v154)

## 1) تطبيق حزمة الأمان والأداء المرفقة
استبدل الملفات التالية في مجلد موقعك قبل الرفع إلى Cloudflare Pages:
- `_worker.js`: إزالة `LEGACY_VAULT_SECRET`، تقييد CORS، إضافة Rate Limit لـ `/api/tts`، وتحويل `userGrantBlock` إلى `fail-closed` عند أخطاء الشبكة.
- `firestore.rules`: حماية `site/ai_vault`، مطابقة `ownerUid` في `gameScores` و`hwSubmissions`، وحصر حذف `resources` على الإدارة. (انشرها من Firebase Console → Firestore → Rules).
- `_headers`: تفعيل سياسة `Content-Security-Policy` كاملة.
- `sw.js`: تقليص التخزين المبدئي إلى الهيكل الأساسي (App Shell) وتخزين باقي الأدوات عند الطلب.

## 2) إعدادات لوحة Cloudflare وFirebase
1. في **Cloudflare Pages → Settings → Environment variables**: أضف `VAULT_SECRET` (سلسلة عشوائية طويلة) واربط KV Namespace باسم `AI_KEYS`.
2. في **Firebase Console → App Check**: سجّل الموقع بـ reCAPTCHA v3 وضع المفتاح في `window.EDUTECH_APPCHECK_SITE_KEY` داخل `firebase-config.js`.

## 4) خطة تقسيم ملفات `js/` الضخمة (3.58 MB → تحميل فوري)
1. **النواة الموحدة (`js/core/utils.js`)**: جمع `escapeHtml`, `safeUrl`, `toast` في ملف واحد بدل تكرارها.
2. **التحميل الكسول (`Lazy Loader`)**: تحويل استدعاءات `<script defer src="js/...">` في `index.html` للأدوات الفرعية (`master-hierarchy.js` 560KB، `bookreader.js` 121KB، `games.js` 85KB، `cvbuilder.js` 77KB) إلى تحميل ديناميكي عند نقر المستخدم على الأداة فقط:
```javascript
const loaded = new Set();
async function loadToolModule(src) {
  if (loaded.has(src)) return;
  await new Promise((res, rej) => {
    const s = document.createElement('script');
    s.src = src; s.onload = res; s.onerror = rej;
    document.head.appendChild(s);
  });
  loaded.add(src);
}
```
