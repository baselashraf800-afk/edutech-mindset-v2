# دليل الإصدار 220 — إصلاح ظهور الإعلانات للزوار، إدارة الدورات الشاملة، وروابط التسجيل المباشر

## أبرز ما تم إنجازه في الإصدار 220
| المحور | التحديث المنفّذ |
|---|---|
| ظهور لوحة الإعلانات للجميع | نقل قراءة وحفظ شرائح الإعلانات إلى وثيقة عامة مباشرة `site/slides_public` (تتجاوز قيد `ai_vault` في Firestore)، مع مزامنة تلقائية للإعلانات القديمة فور فتح الموقع بحساب الإدارة |
| إضافة وتعديل وحذف الدورات | ربط الدورات بوثيقة سحابية `site/courses_catalog` مع واجهة CRUD كاملة في تبويب «🎓 الدورات والتسجيل» (إضافة، تعديل، حذف، وحقل رابط مجموعة واتساب/تيليجرام يظهر للمتدرب بعد التسجيل) |
| دمج رابط التسجيل مع أي إعلان | إضافة قائمة «ربط الإعلان بتسجيل دورة» داخل نموذج الإعلان، وإضافة زر «🔗 نسخ رابط التسجيل» (`?enroll=COURSE_ID`) لنشره على فيسبوك وواتساب وتيليجرام بحيث يفتح استمارة الدورة تلقائياً |
| تبويب «المناهج والكتب» للإدارة | إضافة تبويب موحّد داخل مركز التطوير لإضافة وحذف روابط كتب PDF وفيديوهات الشرح لأي صف ومادة |
| تنظيف التداخلات على الجوال | إخفاء زر EduTech الدائري المكرر أسفل اليمين، رفع أيقونة المساعد الذكي فوق الشريط السفلي، وضغط شريط الإدارة العلوي في سطر واحد قابل للتمرير على الجوال |
| تسريع وتنظيف الموقع | حذف `css/style.css` غير المستخدم، وتأجيل تحميل السكربتات الثانوية (`sound.js`, `gsearch.js`, `diagnostics.js`) لما بعد استقرار الصفحة |
