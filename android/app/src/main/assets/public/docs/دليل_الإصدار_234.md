# دليل الإصدار 234 — قارئ الكتب المدرسي الطبيعي (بلا Markdown) ودمجه داخل المراحل الدراسية

## أبرز ما تم تطويره في الإصدار 234
| المحور | التحديث المنفّذ |
|---|---|
| إلغاء Markdown تماماً عن الطالب | إزالة عبارات `Markdown (.md)` وبناء محرك تنسيق `formatNaturalTextbookHtml` في `src/js/bookreader.js` يحوّل الدروس إلى صفحة كتاب مدرسي طبيعية بعناوين ملونة وصناديق «💡 تذكّر/تعريف» ونقاط مرتّبة |
| الدمج المباشر داخل المراحل الدراسية (`#learnSection`) | إضافة زر «👁️ معاينة الكتاب PDF هنا» داخل تبويب «📖 الكتاب» لكل مادة لمعاينة الكتاب الوزاري الأصلي مباشرة في نفس الصفحة، وزر «📖 فتح الكتاب في القارئ التفاعلي» للتظليل وتحويل الفقرات إلى أدوات |
| وضع ملء الشاشة والاستماع الفصيح | إضافة زر «⛶ ملء الشاشة» وزر «🔊 استمع للدرس» (بمحرك `EduTechTTS` العربي الفصيح) داخل قارئ الكتب |
