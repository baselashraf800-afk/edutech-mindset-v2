# دليل الإصدار 223 — جرس الإشعارات السحابي وشهادات الإتمام الرسمية بـ QR Code

## أبرز ما تم إنجازه في الإصدار 223
| المحور | التطوير المنفّذ |
|---|---|
| جرس الإشعارات الذكي (🔔) | إضافة `src/js/notifications.js` بزر جرس وشارة عدد الإشعارات غير المقروءة في الهيدر، مع قراءة مباشرة من `site/notifications_public` لجميع الزوار |
| إدارة الإشعارات من مركز التطوير | إضافة تبويب «الإشعارات 🔔» في مركز تطوير وتخصيص الموقع لنشر إشعارات فورية (مع إمكانية ربطها بدورة أو رابط مباشر) وحذفها |
| شهادات الإتمام الرسمية بـ QR Code | ترقية إصدار الشهادات داخل الدورات (`openVerifiedCertificate`) لتوليد شهادة A4 أفقية احترافية قابلة للطباعة والحفظ كـ PDF مع رمز QR للتحقق الفوري |
| شاشة التحقق الفوري من الشهادة | دعم فتح رابط التحقق `?verify=CERT_ID` تلقائياً لعرض بطاقة اعتماد الشهادة الرسمية عند مسح رمز QR |
