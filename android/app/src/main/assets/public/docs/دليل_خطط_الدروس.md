# مولّد خطط الدروس

1) **انشر قواعد Firestore المحدّثة** (ملف firestore.rules): فيها قاعدة `lessonplans`، وخطط كل معلم خاصة به.
2) القسم يظهر بعد «مولّد أوراق العمل»، ويمكن إخفاؤه أو نقله من تخصيص الموقع ← الأقسام.
3) اكتب موضوع الدرس أو صوّر صفحته، واختر المرحلة والنموذج (وزاري مفصّل / مبسّط) وعدد الحصص (1 = حصة واحدة، 2-5 = وحدة) وزمن الحصة. تُولَّد كل حصة بطلب مستقل بالتوازي.
4) عدّل أي جزء (النتاجات، الأنشطة بزمنها ودور المعلم والطالب، التقويم…) أو أعد توليد حصة واحدة.
5) PDF عبر نافذة الطباعة (حفظ كملف PDF). Word ينزّل ملف .doc قابلاً للتعديل ويُفتح في Word وGoogle Docs.
6) اسم المدرسة والمعلم يُحفظان في المتصفح وتشاركهما أداة أوراق العمل.
