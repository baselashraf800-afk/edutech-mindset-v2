# دليل الإصدار 221 — النقلة النوعية: الأدوات المنظمة، إحصائيات الإدارة، تحفيز الطالب، وPWA

## أبرز ما تم إنجازه في الإصدار 221
| المحور | التطوير المنفّذ |
|---|---|
| بوابة الأدوات والمختبرات المنظّمة | إنشاء `src/js/tools-hub.js` لتصنيف جميع الأدوات (40+ أداة) في 3 تبويبات واضحة (أدوات الطالب، أدوات المعلم، الذكاء والمختبرات) + تبويب «⭐ المفضّلة» + بحث فوري |
| لوحة الإحصائيات للمدير | إضافة تبويب «الإحصائيات 📊» داخل مركز التطوير يعرض عدد الدورات، إجمالي المسجلين، الإعلانات النشطة، الكتب، توزيع المسجلين لكل دورة، أحدث الطلبات، وتصدير CSV فوري |
| تتبّع إنجاز الطالب ومؤقت المذاكرة | إضافة شريط «📈 تقدّمي في صفّي» وزر تعليم المادة كمُنجزة، بالإضافة إلى مؤقت المذاكرة الذكي (Pomodoro 25 دقيقة / 5 دقائق استراحة) داخل كل مادة في بوابة المناهج |
| المشاركة وتطبيق الجوال (PWA) | تحسين بطاقات المشاركة (Open Graph) لواتساب وفيسبوك، وإضافة شريط تثبيت تطبيق أنيق وقابل للإغلاق للأندرويد والآيفون في `src/js/pwa.js` |
