4. **أيقونة ذكاء اصطناعي جميلة + نافذة مساعد مرتّبة وتستغل كامل الشاشة:** أيقونة نجمة ذكاء متوهجة جديدة، ترويسة مضغوطة في سطر واحد، وتوسيع مربع الكتابة بعرض كامل فوق شريط المرفقات.
