# دليل الإصدار 219 — بوابة المراحل الدراسية والكتب والمناهج الموحّدة

## أبرز التطويرات
| المحور | التغيير المنفّذ |
|---|---|
| بوابة الطالب الموحّدة | إنشاء `src/js/curriculum-hub.js` بتصميم بسيط في 3 خطوات فقط: اختيار المرحلة والصف ← اختيار الفصل والمادة ← صفحة المادة الموحّدة |
| تقسيم المراحل الفلسطينية | اعتماد 4 مراحل واضحة: الأساسي الدنيا (1–4)، الأساسي العليا (5–9)، الثانوي (10–11)، والتوجيهي (12) في بطاقة مميزة لوحده |
| فروع التوجيهي | إبراز الفرع العلمي والأدبي في الصف الأول، وتحتهما باقي الفروع (الشرعي، الريادة والأعمال، التكنولوجي/الصناعي) مع زر حاسبة المعدل |
| صفحة المادة الموحّدة | جمع كل محتوى المادة في 4 تبويبات نظيفة: الكتاب الوزاري (قراءة مباشرة + تحميل PDF)، دروس الشرح، الملخصات والاختبارات، ومساعد المادة الذكي |
| حفظ «صفّي» + البحث الفوري | حفظ صف الطالب تلقائياً للزيارات القادمة، مع خانة بحث سريعة عن أي كتاب أو مادة |
| إلغاء التكرار نهائياً | توجيه زر «كتاب الوزارة» في الشريط السريع إلى البوابة الموحّدة، وضبط القسم المنظّم أسفلها على الأدوات والمختبرات لمنع تكرار الشجرة القديمة |
