# دليل الإصدار 230 — الصوت البشري السلس (ElevenLabs & Gemini) والترحيب الصوتي التلقائي عند أول لمسة

## أبرز التحسينات في الإصدار 230
| المحور | التحديث المنفّذ |
|---|---|
| الترحيب الصوتي التلقائي عند أول لمسة | تشغيل الترحيب الصوتي الدافئ تلقائياً فور أول لمسة أو نقرة للزائر (مرة واحدة في الجلسة لتجاوز قيد Autoplay في Chrome/Safari بسلاسة) |
| ربط المساعد الذكي بالصوت البشري الطبيعي | توجيه `speakResponseWithPersona` في `src/js/assistant.js` مباشرة إلى `EduTechTTS` (ElevenLabs ← Gemini 2.5 TTS ← Web Speech) بدل الصوت الآلي القديم |
| ضبط نبرة صوت بشرية طبيعية | إضافة `voice_settings` متوازنة في ElevenLabs (`stability: 0.45, similarity_boost: 0.78, style: 0.35, use_speaker_boost: true`) وتنظيف النص تلقائياً من الإيموجي والروابط والرموز قبل النطق |
