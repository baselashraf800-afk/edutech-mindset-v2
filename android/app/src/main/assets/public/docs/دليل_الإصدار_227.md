# دليل الإصدار 227 — الصوت العربي الهجين (ElevenLabs & Gemini TTS) + وضع القائد الخارق للإدارة + الافتتاح السلس

## أبرز ما تم إنجازه في الإصدار 227
| المحور | التطوير المنفّذ |
|---|---|
| دمج حزمة الصوت الهجين داخل `_worker.js` | دمج ElevenLabs (`eleven_flash_v2_5`) ثم Gemini 2.5 Flash TTS ثم Azure/Edge ثم Web Speech API مباشرة في مسار `/api/tts` داخل `_worker.js` (لتفادي تجاهل `functions/` في Cloudflare Pages) |
| عميل الصوت والافتتاح السلس (`src/js/tts-client.js`) | إضافة بطاقة ترحيب افتتاحية خفيفة وسلسة مع زر «🔊 استمع للترحيب» وأزرار اختيار الدور السريع (طالب / توجيهي / معلم) + دعم `[data-tts-target]` و`EduTechTTS.speak()` |
| وضع القائد الخارق للإدارة (`src/js/admin-agent.js`) | خاص بحساب الإدارة العليا فقط وبلا أي سقف يومي؛ يضيف شريط أوامر القائد السريعة داخل المساعد، وينفّذ أوامر الإدارة الحقيقية بالصوت أو الكتابة (نشر إشعار، فتح استوديو Flow، كشف PDF، إدارة الدورات، وتعديل حدود المساعد) مع رد صوتي تلقائي |

## متغيرات البيئة الاختيارية في Cloudflare Pages (Settings → Variables and Secrets)
- `ELEVENLABS_API_KEY` (Secret) + اختياري `ELEVENLABS_VOICE_ID` ← الأولوية 1 للصوت الطبيعي.
- `GEMINI_API_KEY` (Secret) ← الأولوية 2 للصوت الطبيعي.
- في حال عدم إضافتهما، يعمل **Web Speech API** العربي مجاناً وبلا حدود تلقائياً.
