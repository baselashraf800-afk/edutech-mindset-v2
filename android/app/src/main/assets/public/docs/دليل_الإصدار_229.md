# دليل الإصدار 229 — إصلاح تعطل الأصوات (ElevenLabs & Gemini TTS) وإغلاق أخطاء التشخيص والثغرات

## المشاكل التي تم اكتشافها وإصلاحها في الإصدار 229
| المشكلة المكتشفة | السبب الجذري | الإصلاح المنفّذ |
|---|---|---|
| تعطل الأصوات السحابية (ElevenLabs وGemini) | خطأ `ReferenceError: corsHeaders is not defined` داخل مسار `POST /api/tts` في `_worker.js`، بالإضافة لضرورة إعادة النشر بعد إضافة Secrets في Cloudflare | إصلاح ترويسات CORS داخل `POST /api/tts` + فحص المصدر `originAllowed` لحماية مفاتيحك من الاستغلال الخارجي + إظهار حالة `elevenLabsTts` و`geminiTts` في `/api/health` |
| خطأ `Uncaught TypeError: Cannot set properties of null (setting 'className')` في تقرير التشخيص | تعيين `.className` مباشرة في `src/js/app.js` لعناصر قد لا تكون موجودة على الجوال | إضافة فحص أمان (`if (el)`) لكل تعيينات `.className` في `src/js/app.js` |
| تقوية سياسة الأمان CSP (`_headers`) | وجود `cdn.tailwindcss.com` غير المستخدم في `script-src` | إزالة النطاق غير المستخدم لتقليص سطح الهجوم في CSP |
