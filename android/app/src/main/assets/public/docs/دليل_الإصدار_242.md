# دليل الإصدار 242 — EduTech Mindset

## أبرز التطويرات:
1. **إصلاح مركز الأدوات بالكامل:** إصلاح قراءة أيقونات الأدوات (`ico`)، قفل عرض الشبكة داخل شاشة الجوال 100% دون أي قصّ يساري، وعرض 6 أدوات أساسية مرتّبة لكل مسار مع زر «عرض باقي الأدوات الإضافية».
2. **تفكيك الملفات والتحميل الذكي حسب الدور (`module-loader.js`):** فصل حزمة الإدارة (`ai-admin.js`, `social-studio.js`, `admin-agent.js`) بحيث لا تُحمَّل للطلاب نهائياً، وتأجيل تحميل الحزم الثقيلة (`edutech-pro-pack.js`, `assistant.js`, `exam.js`) للتحميل عند الطلب (توفير ~420 KB عند فتح الصفحة).
3. **وضع الدراسة بدون إنترنت 80%:** زر «حفظ للعمل دون إنترنت» مع شريط تقدم، وشريط حالة أوفلاين فوري عند انقطاع الشبكة.
4. **مساري الشخصي + تحدي اليوم + بطاقة إنجاز لواتساب (`personal-hub.js`):** حفظ المسار المختار، تحدي 3 مهام يومية مع نقاط XP وسلسلة أيام، ومولّد بطاقة إنجاز PNG قابلة للمشاركة على واتساب.
5. **أدوات الدرس الذكية المدمجة داخل كل مادة:** 4 أزرار فورية داخل كل مادة (استمع للشرح بصوت المعلمة، ملخص كورنيل سريع، بطاقات حفظ قلّابة، واختبار 5 أسئلة أوفلاين).
6. **تجربة PWA متكاملة:** شاشة إقلاع سريعة بشعار المنصة مع اختصارات التطبيق.
