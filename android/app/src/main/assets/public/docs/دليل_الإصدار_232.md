# دليل الإصدار 232 — المراحل الأصلية، إصلاح فتح الأدوات، أصوات فصحى ذكورية/أنثوية بلا تأخير، وتسريع الجوال

## أبرز ما تم إصلاحه وتطويره في الإصدار 232
| المحور | التحديث المنفّذ |
|---|---|
| المراحل الأصلية كأساس للطالب | إبراز قسم المراحل الأصلية (`#learnSection` بالبطاقات الأربع الملونة) مباشرة في الرئيسية وإلغاء البوابة المكررة |
| إصلاح «تم فتح الأداة ولا أراها» | إجبار إظهار الأداة المفتوحة فوراً وبعد التحميل الكسول مع شريط «← العودة لبوابة الأدوات» |
| أصوات عربية فصحى حسب الشخصية وبلا تأخير | اختيار صوت ذكوري/أنثوي تلقائياً في `_worker.js` و`assistant.js` (ElevenLabs ← Gemini `Orus`/`Kore` ← Edge Neural `Hamed`/`Zariyah`) + تقطيع النص وتحميل الجملة التالية مسبقاً لإزالة التأخير + الترحيب التلقائي بصوت أ. باسل عند أول لمسة |
| إصلاح اختفاء الرموز وتخفيف ثقل الجوال | تحميل Font Awesome مباشرة + أيقونات أصلية ثابتة في الهيدر، منع إخفاء صور الإعلانات في وضع توفير البيانات، وتخفيف `backdrop-filter` والأنيميشن على الجوال |
| الشريط السفلي الموحّد للجوال | الترتيب النظيف: الرئيسية | المراحل | الأدوات | الدورات | حسابي |
