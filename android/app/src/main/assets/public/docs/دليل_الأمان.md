1. Cloudflare ← Workers & Pages ← مشروع edutech-mindset ← Settings ← Variables and Secrets ← Add.
2. النوع: Secret، الاسم: VAULT_SECRET، القيمة: عبارة طويلة عشوائية (30 حرفاً أو أكثر) واحتفظ بنسخة منها في مكان آمن.
3. أعد النشر (Production). ثم افتح «المحركات الذكية» واضغط «حفظ» على أي مفتاح، فتُعاد كتابة كل المفاتيح مشفّرة بالسر الجديد.
4. لا تغيّر VAULT_SECRET بعد ذلك، وإلا لن تُقرأ المفاتيح وستحتاج إدخالها من جديد.
