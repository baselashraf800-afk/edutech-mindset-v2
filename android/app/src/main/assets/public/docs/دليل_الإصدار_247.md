# دليل الإصدار 247 — EduTech Mindset

## أبرز الإصلاحات الفورية:
1. **إصلاح زر «تحديث الكاش و Service Worker فوراً» و«تنزيل تقرير التشخيص»:** استعادة `window.EduDiag.purgeCache()` و`download()` داخل `extras.js` لمسح الكاش وإلغاء تسجيل الـ Service Worker القديم وإعادة التحميل بلمسة واحدة.
2. **إصلاح واجهة المساعد الذكي من داخل CSS الخاص به (`assistant.js`):** تعديل تنسيقات `.ea-in` و`.ea-hd` داخل `assistant.js` مباشرة لتظهر الترويسة في سطر واحد وشريط الكتابة في صفّين مريحين دون أي تداخل.
3. **موشن جرافيك حيّ ومرئي فوراً في أعلى الموقع (`#eduLiveMotionBanner`):** لوحة حركة 60fps بألوان متدرجة متحركة، حلقات مدارية دوّارة، عنوان مضيء متحرك، وأيقونات تعليمية طافية تظهر فور فتح الصفحة على الجوال.
