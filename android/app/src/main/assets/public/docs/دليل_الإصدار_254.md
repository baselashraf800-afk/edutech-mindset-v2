# دليل الإصدار 254 — EduTech Mindset

## أبرز الإصلاحات والتطويرات:
1. **وضع نهاري وليلي تلقائي يتبع نظام هاتف المستخدم (`prefers-color-scheme`):** يتبدل الموقع تلقائياً بين النهاري والليلي مع نظام الهاتف، مع إصلاح شامل لتباين النصوص والخلفيات في الوضع النهاري (`#f1f5f9` و`#0f172a` و`#334155`).
2. **تفعيل كل أزرار «القائمة الشاملة» 100%:** إعادة ربطها بالأقسام والأدوات الحقيقية مباشرة (الرئيسية، المراحل، مركز الأدوات الـ 20، استوديو الصوت الذكي، الدورات، التوجيهي، صانع CV، حسابي، ولوحة الإدارة الموحّدة).
3. **إصلاح قسم وزر «🎓 الدورات» السفلي:** تثبيت `#coursesSection` داخل `<main>` لضمان فتحه والتمرير إليه فوراً.
4. **إزالة المربعين الفارغين في بطاقات المراحل (`⬆️` `⬇️`)** وإخفاء بطاقة النقاط المكررة لتبقى بطاقة البداية الموحّدة نظيفة ومرتّبة.
