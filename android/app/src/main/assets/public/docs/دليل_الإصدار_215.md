# الإصدار 215 — الإصلاح والتقوية

## ما تغيّر
| الملف | التغيير |
|---|---|
| `_worker.js` | قراءة خزينة المفاتيح بتوكن الإدارة فقط (القراءة المجهولة كانت تفشل بصمت)؛ حفظ مفتاح من نسخة جديدة لا يمحو مفاتيح المحركات الأخرى؛ رسالة صريحة إن لم يوجد تخزين دائم؛ حد الدقيقة بالذاكرة (بلا كتابة KV)؛ سقف يومي للزائر المجهول (`AI_ANON_DAILY_LIMIT`=20)؛ حد TTS = 60/دقيقة (`TTS_PER_MIN`)؛ دعم Azure Speech الرسمي؛ تحويل نطاقات المعاينة داخل الكود |
| `firestore.rules` | تحقق من أنواع `pct/secs/correct/answers/set` ومطابقة `pct` للدرجة؛ قائمة حقول مغلقة لـ `courses_enrollments` + حدود أطوال + `ticketId == docId` |
| `js/edutech-pro-pack.js` | رقم التذكرة 6 خانات (كان 900 احتمال فقط فتتصادم التسجيلات ويضيع بعضها بصمت) |
| `sw.js` | تخزين مسبق بمسارات `?v=` الصحيحة وكل الوحدات؛ لا addAll كل-أو-لا-شيء؛ لا تخزين لـ `/api/*`؛ لا تضخم الكاش |
| `_headers` | CSP: إزالة unpkg/jsdelivr، إضافة `youtube-nocookie.com` (كان محجوباً)، `object-src 'none'`؛ كاش immutable لـ js/css |
| `js/voice.js` | تحميل مسبق للمقطع الصوتي التالي (إزالة الفجوات) |
| `js/core-utils.js`, `app.js`, `master-hierarchy.js` | تحديد محاولات رمز الإدارة (5 ثم قفل 5 دقائق) + دعم بصمة PBKDF2 مملّحة |
| `_redirects` | أُفرغ؛ التحويل صار في الـ Worker |
| `tools/` | `bump-version.sh`، `smoke_test.sh`، `make-pin-hash.js` |

## خطوات يدوية مطلوبة منك (لا يمكن عملها من الكود)
1. **Cloudflare → Pages → Settings → Bindings**: أضف KV Namespace باسم `AI_KEYS` (يحفظ المفاتيح والحد اليومي).
2. **Variables**: `VAULT_SECRET` (نص عشوائي ≥ 32 حرفاً)، اختيارياً `REQUIRE_LOGIN=true`، `AZURE_SPEECH_KEY` + `AZURE_SPEECH_REGION` للصوت الرسمي.
3. **Firebase → Firestore → Rules**: الصق `firestore.rules` الجديد ثم Publish.
4. **App Check**: Firebase → App Check → سجّل تطبيق الويب بـ reCAPTCHA v3 → الصق Site Key في `EDUTECH_APPCHECK_SITE_KEY` داخل `firebase-config.js` → راقب أسبوعاً ثم فعّل Enforce لـ Firestore.
5. **رمز الإدارة**: `node tools/make-pin-hash.js "رمز طويل"` ثم استبدل قيمة `ADMIN_PIN_HASH` في `js/app.js` (والرمز في master-hierarchy لا يزال بالصيغة القديمة).
6. بعد كل تعديل على js/css شغّل `bash tools/bump-version.sh <رقم>` وإلا لن يرى الزوار التعديل (الكاش سنة).
7. بعد النشر: `bash tools/smoke_test.sh`.

## لم يُنفَّذ (يحتاج قراراً أو عملاً أكبر)
- تصحيح الاختبارات من جهة الخادم (الدرجة ما زالت تُحسب في متصفح الطالب).
- إزالة `unsafe-inline` من CSP (يتطلب تحويل ~100 معالج onclick).
- تقسيم الحزم الكبيرة (master-hierarchy 580KB وغيرها) — يحتاج أداة بناء واختبار انحدار.
