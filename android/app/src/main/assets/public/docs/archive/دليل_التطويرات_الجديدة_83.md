# تطويرات النسخة 83 — بوابة الخيار الجامعي واستوديو بناء السيرة الذاتية الاحترافية (CV) باللغتين العربية والإنجليزية

## 1. إطلاق «📄 استوديو بناء السيرة الذاتية الاحترافية الثنائية اللغة (Arabic & English ATS CV Builder)» (`#cvBuilderStudio` و `js/cvbuilder.js`)
- **دعم كامل للغتين العربية (`RTL`) والإنجليزية (`LTR`) جنباً إلى جنب:**
  - إمكانية تحرير ومعاينة السيرة الذاتية باللغة العربية وحدها، أو باللغة الإنجليزية وحدها، أو في **وضع المعاينة المزدوجة (`عربي + English معاً`)**.
- **مترجم أكاديمي ومهني ذكي مدمج (`🔄 ترجم للإنجليزية / العربية`):**
  - يترجم المسميات الوظيفية، التخصصات، والجامعات الفلسطينية والعربية (بيرزيت، النجاح، الإسلامية، الأزهر، القدس، الخليل، بوليتكنك فلسطين، القدس المفتوحة، الأقصى...) والمهارات تلقائياً بلا إنترنت أو بصياغة احترافية عبر الذكاء الاصطناعي.
- **6 قوالب تخصصية جاهزة لطلاب الجامعات والخريجين والمعلمين (بالعربية والإنجليزية):**
  1. **💻 هندسة حاسوب وذكاء اصطناعي وتطوير برمجيات (`IT / Software & AI Engineer`).**
  2. **👨‍🏫 خريج تربية ومعلم متميز (`STEM Educator & Instructional Designer`).**
  3. **📊 إدارة أعمال ومحاسبة وتحليل مالي (`Business, Accounting & Finance`).**
  4. **🔬 سيرة ذاتية أكاديمية وبحثية للمنح والدراسات العليا (`Academic & Scholarship CV`).**
- **3 أنماط تصميمية احترافية:**
  - `🏛️ قالب ATS القياسي (Harvard Standard)` • `✨ القالب العصري التنفيذي (Modern Executive)` • `🎓 القالب الأكاديمي الجامعي (Academic)`.
- **مؤشر جودة السيرة الذاتية (`ATS Score Meter 0–100%`) + مولّد خطاب التقديم (`Cover / Motivation Letter`):**
  - يقيم اكتمال السيرة الذاتية لحظياً، ويولّد خطاب تقديم للوظائف أو المنح الجامعية باللغتين العربية والإنجليزية بضغطة زر.
- **تصدير متعدد الصيغ:**
  - **طباعة وتصدير `PDF` بمقاس `A4`** (النسخة العربية، أو الإنجليزية، أو النسختين معاً في ملف واحد).
  - **تنزيل ملف `Word (.doc)`** قابل للتعديل.
  - **تنزيل وحفظ بصيغة `Markdown (.md)`** مباشرة في قاعدة بيانات الموقع.

## 2. تفعيل «🎓 الخيار الجامعي والخريجون» في كافة أقسام المنصة
- **بوابة مستقلة في شريط الأدوار (`🎓 الجامعي والـ CV`):** تضم 4 مراحل متكاملة للطالب الجامعي والخريج (السيرة الذاتية والتوظيف ← الكتب الجامعية وتحويل PDF لـ Markdown ← البحث الأكاديمي والخرائط الذهنية ← عروض مشاريع التخرج والبرمجة).
- **دمج المرحلة الرابعة «المرحلة الجامعية والتأهيل المهني» في قسم المراحل الدراسية (`js/learn.js`)** مع لافتة مباشرة لفتح منشئ السيرة الذاتية.
- **دمج تبويب «📄 إنشاء CV جامعي احترافي (عربي/EN)» داخل بوابة التوجيهي والمستشار الجامعي (`js/tawjihi.js`)** وفي مولّد الذكاء الاصطناعي (`index.html`).
