# الإصدار 149 — الدخول بالبريد، حماية الخادم، المزامنة، البحث الشامل، توفير البيانات

## خطوات التفعيل (مرة واحدة، ~5 دقائق)
1. **Firebase Console ← Authentication ← Sign-in method ← Email/Password ← Enable** (بدونها يظهر للمستخدم: «الدخول بالبريد غير مفعّل بعد»).
2. **Firestore ← Rules**: الصق محتوى `firestore.rules` من هذه النسخة ثم Publish (أُضيفت قاعدة `assistant/{uid}`).
3. ارفع الـ ZIP على Cloudflare Pages كالمعتاد (الـ Worker جزء منه ويتحدّث تلقائياً).
4. (اختياري للسرعة) بناء Tailwind: `cd tools/tailwind-build && npm install && npm run build && npm run apply`.

## الجديد
- **دخول وتسجيل بالبريد وكلمة المرور** (Firebase): تبويبا دخول/حساب جديد، «نسيت كلمة المرور»، رسالة تحقق للبريد. يظهر زر «بالبريد» في الرأس، وأزرار «تسجيل الدخول/حساب جديد» في شاشة الترحيب تفتحه. لا يظهر إلا إذا كان Firebase متصلاً؛ وإلا يبقى الحساب المحلي كما هو.
  - صلاحياتك المركزية (grants) تتطلب بريداً موثّقاً، لذلك يُطلب من المستخدم الجديد تأكيد بريده.
- **حماية من جهة الخادم**: `_worker.js` يرفض طلبات الذكاء الاصطناعي للحساب الموقوف أو للأداة المحجوبة عنه بقرار الإدارة (يقرأ grants/{email}). عند تعذّر القراءة يسمح بالطلب كي لا تتعطل الخدمة. قواعد Firestore كانت محكمة أصلاً وبقيت.
- **مزامنة «مساعدي»** بين الأجهزة عبر الحساب (آخر تعديل يفوز؛ المحادثة تبقى محلية).
- **البحث الشامل**: Ctrl+K أو «/» أو زر «بحث» في الرأس: الأدوات + أقسام الصفحة + مهامي وملاحظاتي + اسأل المساعد.
- **وضع توفير البيانات**: تلقائي مع الاتصال الضعيف، أو من «مساعدي ← ⋯ ← 5». يقلل الحركة والتمويه ويؤجل الصور، مع تنبيه عند انقطاع الإنترنت.
- **الهوية**: علامة مائية وترويسة على كل ملفات Word/PDF والطباعة (من 148).

## حدود يجب معرفتها
- لم أختبر الدخول بالبريد على Firebase حقيقي (اختبرت الواجهة والتدفق بمحاكاة). جرّب بحساب تجريبي بعد التفعيل.
- فرض الأداة على الخادم يشمل الذكاء الاصطناعي فقط؛ الأدوات التي تعمل محلياً بلا خادم تُحجب في الواجهة.
- المزامنة: تعديلان متزامنان دون اتصال على جهازين → يفوز الأحدث.
