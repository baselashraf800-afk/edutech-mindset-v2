# دليل التطويرات الشاملة للمرحلة الرابعة (الإصدار 46) — EduTech Mindset

يضيف **الإصدار 46** ثلاث منظومات ذكية جديدة للمعلم والطالب والمشرف التربوي:

## 1. 📸 نظام الواجبات المصوّرة والتصحيح البصري لدفاتر الطلاب (`js/homework.js`)
- ينقسم إلى وضعين متكاملين:
  1. **المصحح البصري الفوري لدفتر الطالب:** يكتب المعلم السؤال، ثم يصوّر دفتر الطالب بالكاميرا (أو يختار صورة)، فيقوم الذكاء الاصطناعي (Vision AI) بقراءة خط يد الطالب، وتحديد نقاط الإجادة، وتصويب الأخطاء، واقتراح الدرجة المستحقة مع رسالة تشجيعية.
  2. **روابط تسليم الواجبات المنشورة (`?hw=ID`):** ينشئ المعلم واجباً منزلياً وينسخ رابطه للطلاب (أو يضيفه مباشرة إلى فصله الافتراضي بزر **«🏫 أضف لفصل»**). يفتح الطالب الرابط ويصوّر حله من دفتره ويرسله بلا حساب، ثم يضغط المعلم **«🤖 تصحيح الجميع بالذكاء الاصطناعي»** لتصحيح كل الدفاتر بضغطة زر!

## 2. 📖 استوديو القصص التعليمية المصوّرة والراوي الصوتي (`js/stories.js`)
- يحوّل أي درس علمي أو قيمة تربوية إلى **قصة مصوّرة من 5 مشاهد** بأبطال يختارهم المعلم أو الطالب:
  - يرسم لوحة فنية تعبيرية مع فقاعة حوار لكل مشهد.
  - **🔊 الراوي الصوتي للمشهد:** يقرأ القصة بصوت عربي واضح مشهداً تلو الآخر.
  - يختتم القصة بالحكمة العلمية وأسئلة فهم واستيعاب مع إجاباتها، وزر **«🖨 طباعة كتيّب القصة PDF»**.

## 3. 📊 مرصد المنصة وإحصاءات تغطية المنهاج (`js/analytics.js`)
- يعرض إحصاءات حية لتوزع الكتب، الفيديوهات، أوراق العمل، الاختبارات، والملخصات عبر كل مرحلة دراسية.
- يكشف المواد التي لم يُضف لها محتوى بعد لتتمكن من إثرائها بضغطة زر.
- زر **«🖨 طباعة تقرير الإنجاز PDF»** يصدر تقريراً رسمياً منسقاً بحجم A4 للمدرسة أو الإشراف التربوي.

---

### تفعيل القواعد المحدثة (Firebase Rules)
لتفعيل حفظ الواجبات المنشورة وتسليمات دفاتر الطلاب (`homeworks` و`hwSubmissions`)، انسخ ملف `firestore.rules` المرفق في هذه الحزمة والصقه في **Firebase Console ← Firestore Database ← Rules** ثم اضغط **Publish**.
