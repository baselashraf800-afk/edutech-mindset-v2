# تطويرات النسخة 88 — استوديو دفتر كورنيل الذكي (Cornell Notebook)، مدرب الاستدعاء النشط (Cloze Active Recall)، والمبسّط الأكاديمي المزدوج

## 1. إطلاق «📓 استوديو دفتر كورنيل الذكي ومدرب الاستدعاء النشط» (`#smartNotesFlashStudio` و `js/smartnotes.js`)
- **أولاً — دفتر الملاحظات الذكي بنظام كورنيل العالمي (`Cornell 3-Zone Smart Notebook`):**
  - يقسّم أي فصل أو كتاب من قاعدة بيانات الـ Markdown تلقائياً إلى مناطق كورنيل الثلاث:
    1. **🔑 عمود الأسئلة المفتاحية والكلمات الدلالية (`Cue Column`).**
    2. **📝 عمود الشرح التفصيلي والقواعد والأمثلة (`Detailed Notes Column`).**
    3. **📌 منطقة الخلاصة الذهبية أسفل الصفحة (`Bottom 2-Minute Summary`).**
  - يدعم **«🙈 وضع التسميع الذاتي (إخفاء عمود الشرح)»** ليختبر الطالب أو الباحث الجامعي تذكره النشط من عمود الأسئلة، مع حفظ الدفتر بصيغة `Markdown (.md)` في قاعدة بيانات الموقع أو طباعته بصيغة `PDF`.
- **ثانياً — مدرب الاستدعاء النشط وإكمال الفراغات الذكي (`Cloze Deletion & Active Recall Trainer`):**
  - يحوّل القوانين والفقرات الواردة في الفصل تلقائياً إلى بطاقات إخفاء الكلمات المفتاحية (`Cloze Recall`)، فيكشف المتعلم المصطلح المخفي بنقرة واحدة ويقيّم تذكره (`✅ تذكرتها` / `🔁 أخفِ مجدداً`).
- **ثالثاً — المبسّط والمترجم الأكاديمي للمصطلحات (`Bilingual Academic Explainer — عربي ⇄ English`):**
  - يقدم شرحاً مزدوج المستوى للدرس (**شرح مبسط سريع** + **شرح أكاديمي معمق**) مع جدول المصطلحات العلمية الثنائية اللغة وإرسالها بنقرة واحدة إلى **«المراجعة الذكية بالتكرار المتباعد»**.
