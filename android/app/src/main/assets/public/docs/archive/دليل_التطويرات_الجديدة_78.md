# تطويرات النسخة 78 — منظومة الأدوار الأربعة الموحّدة، بوابة ولي الأمر والجمهور العام، وجسر التكامل الشامل بين الأدوات

## 1. تنظيم الموقع الشامل بين الفئات الأربع (`js/ecosystem.js` + `js/launcher.js`)
- **منسّق الأدوار الأربعة التفاعلي (`#eduRoleOrchestrator`):** شريط قيادة واضح وجذاب أعلى المركز الذكي (مع زر تبديل فوري في الترويسة العلوية) يقسّم تجربة الموقع وينظّمها بدقة بين:
  1. **👨‍🎓 بوابة الطالب (Student):** رحلة تعلم من 5 خطوات مترابطة (افهم درسك ← المعلم الخصوصي والخرائط ← المراجعة الذكية بالتكرار المتباعد ← اختبر نفسك ← فصلي وواجباتي) مع مسار خاص لطلبة التوجيهي والتأسيس.
  2. **👨‍🏫 بوابة المعلم (Teacher):** قيادة صفية متكاملة (حقيبة الحصة الجاهزة ← ورقة عمل واختبار إلكتروني ← السبورة والعرض التقديمي ← إدارة الفصول وسجل الدرجات ← بطاقات أولياء الأمور والشهادات).
  3. **👨‍👩‍👧‍👦 بوابة ولي الأمر والأسرة (Parent):** منظومة جديدة كلياً لمتابعة الأبناء والربط بين البيت والمدرسة.
  4. **🌍 بوابة الجمهور العام والمجتمع (Public):** مساحة معرفية مفتوحة للدورات التدريبية، مكتبة البرومبتات، أطلس فلسطين، الأكاديمية البرمجية، والمسابقات الثقافية.

## 2. إطلاق «👨‍👩‍👧‍👦 بوابة ولي الأمر ومتابعة الأبناء التفاعلية» (`#parentPortalStudio` — الأداة رقم 43)
- **إدارة ملفات الأبناء:** إمكانية تسجيل أكثر من ابن/ابنة، وتحديد الصف الدراسي، ورمز الفصل الدراسي (`GZ-XXXX`)، والمواد التي تحتاج تركيزاً، وهدف الأسرة الشهري.
- **مؤشرات إنجاز حية:** عرض نقاط الخبرة (`XP`)، وسلسلة أيام المذاكرة المتتالية (`🔥 Streak`)، وعدد البطاقات المنجزة في المراجعة الذكية، وآخر درس تصفحه الطالب، ومهام وإعلانات المعلم في الفصل الافتراضي.
- **🤖 المستشار التربوي الأسري وخطة المتابعة المنزلية:** يولّد خطة متابعة منزلية أسبوعية مخصصة لولي الأمر مع إمكانية إرسالها بضغطة زر إلى «المخطط الأسبوعي الذكي»، بالإضافة إلى إصدار **«🏅 شهادة تشجيع من الأسرة»** و**«📋 بطاقة متابعة مصوّرة»**.

## 3. إطلاق «🌍 بوابة الجمهور العام والمجتمع المعرفي» (`#publicHubStudio` — الأداة رقم 44)
- تجمع في واجهة أنيقة ومباشرة جميع خدمات المنصة الموجهة للمجتمع العام، الخريجين، والباحثين: الدورات التدريبية، أطلس فلسطين التفاعلي، مولّد البرومبتات، أكاديمية البرمجة، معمل اللغات، الإذاعة والمسابقات الثقافية، وأداة ضغط الصور وتحويل PDF محلياً.

## 4. جسر التكامل الذكي بين الأدوات (`window.EduBridge`)
- **في حقيبة الحصة الجاهزة (`js/lessonkit.js`):** إضافة شريط «🔗 تكامل الأدوات الذكي» لتحويل الحقيبة المولّدة بضغطة زر إلى:
  - محرر أوراق العمل والاختبار الإلكتروني (`worksheetStudio`).
  - مسابقة ولعبة صفية تفاعلية (`gamesStudio`).
  - عرض تقديمي للشرح (`slidesStudio`).
  - خريطة ذهنية في المعلم الذكي (`tutorStudio`).
  - بنك الأسئلة التفاعلي (`questionBank`) أو جدول الحصص في المخطط الأسبوعي (`weeklyPlannerStudio`).
- **في مولّد أوراق العمل (`js/worksheets.js`):** إضافة أزرار إرسال الأسئلة مباشرة إلى «🧠 المراجعة الذكية بالتكرار المتباعد» وإلى «🗓️ المخطط الأسبوعي».
- **في الكتب المدرسية (`js/books.js`):** إضافة زر «🧳 حقيبة الحصة الكاملة» على كل كتاب مدرسي لتوليد تحضير كامل من أي درس في الكتاب.
- **في الفصول الافتراضية (`js/classrooms.js`):** إضافة زر «🏅 شهادات للمتفوقين» في سجل الدرجات التراكمي لإصدار شهادات تكريم فورية للطلاب المتفوقين بجانب الخطط العلاجية وتقارير أولياء الأمور.
- **في المخطط الأسبوعي (`js/planner.js`):** إضافة «👨‍👩‍👧‍👦 قالب ولي الأمر» لتنظيم جدول المتابعة المنزلية الأسبوعي.
- **في بنك الأسئلة (`js/study.js`):** إضافة زر تحويل أسئلة البنك إلى بطاقات في «🧠 المراجعة الذكية».
