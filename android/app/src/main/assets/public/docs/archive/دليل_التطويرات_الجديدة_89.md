# دليل التطويرات الجديدة — الإصدار 89 (EduTech Mindset v89)

## أبرز الإضافات في الإصدار 89 (`js/stemlabplanner.js` • `#stemLabPlannerStudio`)

1. **المختبر التفاعلي للمعادلات وحل المسائل خطوة بخطوة (STEM Step-by-Step Solver & Live SVG Plotter)**:
   - يدعم مسائل الفيزياء (الميكانيكا والكهرباء RC)، الرياضيات (التفاضل والقيم القصوى والتكامل المحدود)، الكيمياء (قانون الغازات المثالية)، وعلم الحاسوب (تحليل تعقيد الخوارزميات Big-O).
   - يوفر تفكيكاً منهجياً من 5 خطوات مع ميزة **إخفاء الخطوات للتدرب الذاتي (`🙈`)** أو كشفها خطوة بخطوة، مع **محاكي متغيرات حيّ (Sliders)** يرسم المنحنى البياني `SVG` مباشرة.
2. **مخطط الجداول الدراسية الذكي ومؤقت بومودورو التكيفي (`Smart Study Timetable & Adaptive Focus Sprint`)**:
   - يولّد جدول مراجعة أسبوعي مرتبطاً مباشرة بفصول الكتب المفعّلة وقاعدة بيانات الـ Markdown (`500 MB`) مع وضع الطوارئ المكثف للامتحانات.
   - يضم مؤقت بومودورو تفاعلياً (`25 د تركيز` / `50 د مذاكرة معمقة` / `5 د استراحة`) يسجّل الجلسات المنجزة في مرصد الإتقان.
3. **مدقق الأصالة اللغوية وإعادة الصياغة الأكاديمية المزدوجة (`Academic Paraphraser & Originality Analyzer — AR/EN`)**:
   - يحسب مؤشر الأصالة والتنوع اللغوي وجودة الترابط الأكاديمي، ويعيد صياغة الفقرات بثلاثة أنماط (أكاديمي رصين، إيجاز تنفيذي، ومزدوج اللغة `عربي ⇄ English`) مع التصدير الفوري إلى `A4 PDF` و`Markdown (.md)`.
