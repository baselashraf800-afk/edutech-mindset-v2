# دليل التطويرات الشاملة للمرحلة الثالثة (الإصدار 45) — EduTech Mindset

يضيف **الإصدار 45** ثلاث منظومات كبرى جديدة كلياً للمعلم والطالب، وتعمل جميعها بكفاءة حتى عند انقطاع الإنترنت:

## 1. 🏅 مولّد الشهادات الجماعية وبطاقات التكريم (`js/certificates.js`)
- يتيح للمعلم أو مدير المدرسة إصدار شهادات تقدير وتفوق لصف كامل دفعة واحدة:
  - الصق قائمة أسماء الطلاب (كل اسم في سطر، ويمكن إضافة `| 98%` لطباعة الدرجة أو التقدير).
  - أو اضغط زر **«🏅 شهادات جماعية للمتفوقين»** داخل نتائج أي اختبار إلكتروني فيرسل أسماء الأوائل ودرجاتهم تلقائياً إلى المولّد!
  - اختر من 5 ثيمات فاخرة (👑 ذهبي ملكي، 🌿 زمردي علمي، 💎 أزرق أكاديمي، ✨ بنفسجي إبداعي، 🌹 قرمزي احتفالي).
  - زر **«✨ صياغة عبارة بالذكاء الاصطناعي»** يكتب لك عبارة تكريم تربوية مؤثرة.
  - زر **«🖨 طباعة / حفظ كل الشهادات PDF»** ينشئ دفتر شهادات A4 أفقي (شهادة مستقلة لكل طالب في صفحة) جاهزاً للطباعة، وزر **«⬇ صورة PNG لهذا الطالب»** ينزّل شهادة الطالب كصورة عالية الدقة لإرسالها عبر واتساب.

## 2. 🧪 مختبر التجارب والمحاكاة العلمية التفاعلية STEM Lab (`js/simlab.js`)
- مختبر افتراضي تفاعلي يعمل محلياً داخل المتصفح بلا إنترنت، ويضم **5 محاكيات علمية ورياضية**:
  1. **⚡ قانون أوم والدوائر الكهربائية:** تحكّم بالجهد ($V$) والمقاومة ($R$) وشاهد تغيّر شدة التيار ($I$) وسطوع المصباح والقدرة الكهربائية.
  2. **🎯 حركة المقذوفات والمدى الأفقي:** غيّر زاوية الإطلاق والسرعة الابتدائية وشاهد مسار المقذوف وأقصى ارتفاع والمدى الأفقي.
  3. **🧪 مقياس الحموضة والمحاليل (pH):** اختبر محاليل مختلفة وحرّك مؤشر الـ pH من 0 إلى 14 مع تغيّر لون الكاشف في الكأس المخبرية.
  4. **🌿 البناء الضوئي وإنتاج الأكسجين:** تحكّم بشدة الإضاءة وتركيز $CO_2$ ودرجة الحرارة وراقب معدل انطلاق فقاعات الأكسجين $O_2$.
  5. **📐 راسم الدوال التربيعية والمثلثية:** غيّر معاملات الدالة ($a, b, c$) وشاهد رسم المنحنى البياني فوراً.
- مع زر **«🤖 اشرح النتيجة وولّد أسئلة استنتاجية»** لتحليل التجربة بالذكاء الاصطناعي.

## 3. 🧰 حقيبة إدارة الصف الذكية والجدول المدرسي الأسبوعي (`js/classtools.js`)
- 4 أدوات يومية للمعلم داخل الغرفة الصفية (تعمل بلا إنترنت وتُحفظ بياناتها على الجهاز):
  1. **🎲 القرعة العشوائية للطلاب:** الصق أسماء طلابك مرة واحدة واختر طالباً للمشاركة بالقرعة دون تكرار حتى يشارك الجميع.
  2. **👥 مقسّم المجموعات التعاونية:** يقسّم طلاب الصف تلقائياً وبالتساوي إلى مجموعات عمل تعاوني (بأسماء علماء: الخوارزمي، ابن الهيثم، الرازي…) مع إمكانية طباعتها.
  3. **⏱ مؤقت الأنشطة الصفية:** عدّاد تنازلي بصري وصوتي (دقيقة، 3، 5، 10، 15 دقيقة) لضبط وقت العمل الجماعي.
  4. **📅 باني الجدول المدرسي الأسبوعي:** جدول الحصص (الأحد إلى الخميس • 7 حصص) يُحفظ تلقائياً ويُطبع كملف PDF أنيق بحجم A4.
