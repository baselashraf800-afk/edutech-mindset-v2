# تطويرات النسخة 82 — توسيع سعة «مصادري» إلى 500 ميغابايت، دعم Markdown، ومحرك تحويل ملفات PDF إلى قاعدة بيانات خاصة بالموقع

## 1. توسيع سعة «مصادري: كتبي وصور صفحاتي» (`js/sources.js`)
- **رفع السعة الإجمالية للمصادر المفعّلة من `7.9 ميغابايت` إلى `500.0 ميغابايت`** (ورفع حد ملف الـ PDF الواحد إلى **`150 ميغابايت`**)، مما يتيح للمعلم أو الطالب رفع وتفعيل جميع الكتب المدرسية للفصل الدراسي دفعة واحدة دون رسائل خطأ.
- **الإرسال الذكي لنصوص الـ Markdown المفهرسة:** عند تحويل الكتاب إلى Markdown، يُرسل النص المهيكل الخفيف (بضعة كيلوبايتات فقط) إلى محرك الذكاء الاصطناعي بدلاً من إرسال ملفات Base64 الضخمة في كل سؤال، مما يضمن سرعة فائقة ودقة كاملة.

## 2. محرك تحويل ملفات PDF إلى Markdown وتسجيلها في قاعدة بيانات الموقع الخاصة (`PDF → Markdown → Site DB`)
- **زر مباشر «⚡ أعطه ملف PDF وحوّله فوراً لـ Markdown وقاعدة بيانات»** داخل قسم «مصادري»، بالإضافة إلى زر **«⚡ حوّل لـ Markdown وسجّل بالقاعدة»** بجانب كل ملف PDF مرفوع.
- **قراءة واستخراج محلي فوري (`pdf.js`) + إثراء بالذكاء الاصطناعي:**
  - يقرأ صفحات ملف الـ PDF محلياً داخل المتصفح صفحة بصفحة مع شريط تقدم حي، ويحولها إلى وثيقة **Markdown (`.md`)** قياسية منظمة.
  - يدعم كذلك الملفات المصوّرة عبر الذكاء الاصطناعي (`AI Vision`) وزر **«🤖 تنظيم وإثراء الـ Markdown بالـ AI»**.
- **التحليل التلقائي والتسجيل في قاعدة بيانات الموقع (`kb_books` في `IndexedDB` + `appState.books` + `EduBookReader`):**
  - يقسّم ملف الـ Markdown تلقائياً حسب العناوين (`## `) إلى فصول ودروس (`lessons`) ويستخرج القواعد والمفاهيم الأساسية (`k`)، ويخمن الصف والمادة والمرحلة الدراسية.
  - يظهر الكتاب المسجل فوراً في:
    1. **جدول «🗄️ قاعدة بيانات الموقع الخاصة (Markdown Knowledge Base)»** داخل قسم مصادري.
    2. **«📖 قارئ ومعاين الكتب التفاعلي»** بكامل فصوله وقواعده القابلة للتظليل والنقل للأدوات الـ 13.
    3. **قسم «📚 الكتب والمناهج»** وتبويب الكتب في **«🏫 المراحل الدراسية»**.

## 3. استوديو ومحرر Markdown المدمج + تصدير واستيراد قاعدة البيانات
- **دعم رفع وإنشاء وتحرير ملفات `.md` / `.markdown` / `.txt`** مباشرة مع معاينة حية منسّقة جنباً إلى جنب (`Split Live Markdown Editor & Preview`).
- **تصدير واستيراد قاعدة بيانات الموقع (`JSON` / `.md`):** إمكانية تنزيل أي كتاب محوّل كملف `.md` أو تصدير قاعدة بيانات الموقع الكاملة كملف `EduTech_Site_Markdown_Database.json` واستيرادها على أي جهاز آخر بنقرة واحدة.
