# تطويرات النسخة 85 — استوديو البودكاست التعليمي التفاعلي، مصفوفة المقارنة والدمج الذكي بين الكتب، وتوسيع البحث الشامل في قاعدة بيانات الـ Markdown

## 1. إطلاق «🎙️ استوديو البودكاست التعليمي التفاعلي ومصفوفة دمج المصادر» (`#multiSourceSynthStudio` و `js/multisynth.js`)
- **أولاً — مولّد الحوار الصوتي التفاعلي والبودكاست التعليمي (`Two-Host Audio Overview`):**
  - يحوّل أي فصل من كتاب أو سجل في قاعدة بيانات الـ Markdown إلى حوار صوتي ممتع بين متحدثَين (**الأستاذ راشد** و**الباحثة سلمى**) يشرحان القواعد والمفاهيم والأمثلة بأسلوب شيق.
  - يدعم **التشغيل الصوتي التفاعلي المباشر (`🔊 تشغيل الحوار الصوتي الآن`)** مع تظليل المقطع المنطوق لحظياً، أو الاستماع لأي فقرة حوارية بنقرة واحدة، وحفظ نص الحلقة كملف `Markdown (.md)` في قاعدة بيانات الموقع.
- **ثانياً — مصفوفة المقارنة والدمج الذكي بين الكتب والفصول (`Multi-Source Comparison & Bloom's Synthesis Matrix`):**
  - يختار المعلم أو الطالب أو الباحث الجامعي فصلين أو كتابين من قاعدة بيانات الموقع، ليولّد المحرك تلقائياً:
    1. **جدول مقارنة منهجي شامل** يوضح الفكرة المحورية والشرح والتطبيق لكل مصدر جنباً إلى جنب.
    2. **ملخصاً تركيبياً موحّداً** يربط بين الموضوعين.
    3. **أسئلة تفكير عليا (وفق مستويات التحليل والتركيب والتقويم في هرم بلوم)** جاهزة للإرسال بنقرة واحدة إلى **مولّد أوراق العمل** أو **حقيبة الحصة الجاهزة** أو حفظها في قاعدة بيانات الموقع.

## 2. تحسين البحث الشامل الموحّد في أعلى الموقع (`js/boost.js`)
- أصبح شريط البحث الموحّد (`#boostBar`) يفهرس تلقائياً **جميع الفصول والقواعد داخل الكتب المدمجة والكتب المحوّلة من PDF إلى Markdown في قاعدة بيانات الموقع**، ويفتح الفصل المطابق مباشرة داخل «قارئ الكتب التفاعلي» عند الضغط على نتيجة البحث.
