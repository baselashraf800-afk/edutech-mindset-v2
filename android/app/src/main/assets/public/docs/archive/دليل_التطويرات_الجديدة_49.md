# دليل التطويرات الشاملة للمرحلة السابعة (الإصدار 49) — EduTech Mindset

يضيف **الإصدار 49** ثلاث منظومات استراتيجية تجعل تصفح المنصة واستخدامها أسرع وأشمل لكل المراحل:

## 1. 🚀 مشغّل الأدوات الموحّد ووضع التركيز الذكي (`js/launcher.js`)
- بعد أن أصبحت المنصة تضم **25 أداة ومنظومة تعليمية**، أضفنا زرّاً عائماً أسفل الشاشة **«🚀 كل الأدوات (25)»** (ويعمل أيضاً باختصار لوحة المفاتيح `Ctrl + K`):
  - يفتح شبكة مصنفة بـ 4 تبويبات (أدوات المعلم، أدوات الطالب، المختبرات والألعاب، والإدارة والتقارير) مع محرك بحث فوري للوصول لأي أداة في ثانية واحدة.
  - **🎯 وضع التركيز (Focus Mode):** عند تفعيله، يعرض لك القسم الذي اخترته فقط ويخفي بقية الأقسام الطويلة من الصفحة لتكون الصفحة خفيفة جداً وسريعة على الهاتف دون تمرير طويل، مع شريط علوي للتبديل السريع أو إظهار كل الأقسام.

## 2. 💻 أكاديمية البرمجة والتكنولوجيا والروبوتكس (`js/codinglab.js`)
- مصممة لدعم منهاج التكنولوجيا والبرمجة الفلسطيني (وتعمل بلا إنترنت):
  - **🤖 خوارزميات الروبوت باللبنات:** 3 مستويات متدرجة يركّب فيها الطالب لبنات الأوامر (`⬆️ تقدم`، `⏫ كرر 2×`، `↪️ انعطف يميناً`) لإيصال الروبوت إلى الهدف وتعلّم التفكير المنطقي.
  - **💻 محرر الكود التفاعلي المباشر (HTML/CSS/JS):** يكتب الطالب الكود أو يعدّل على مشاريع جاهزة (آلة حاسبة، رسم زخارف بالحلقة التكرارية `for loop`، مسابقة تفاعلية) ويرى النتيجة فوراً.
  - **🧠 معلم ومصحح البرمجة الذكي:** يشرح أي كود برمجي أو يصحح أخطاءه بالعربية المبسطة.

## 3. 🫧 مولّد أوراق التظليل الاختبارية (Bubble Sheet) وسلالم التقدير (`js/rubrics.js`)
- **🫧 أوراق التظليل الاختبارية (PDF):** يولّد ورقة إجابة قياسية بدوائر التظليل (`أ - ب - ج - د` أو `صح / خطأ`) لـ 10 إلى 40 سؤالاً بحجم A4 لتصحيح الاختبارات الورقية بسرعة فائقة.
- **📋 مولّد سلالم التقدير اللفظي (Rubrics):** يبني بالذكاء الاصطناعي جدول معايير تقييم المشاريع والأبحاث والعروض (ممتاز / جيد جداً / مقبول / يحتاج تحسين) جاهزاً للطباعة A4.
