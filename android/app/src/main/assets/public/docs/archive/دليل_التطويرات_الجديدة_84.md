# تطويرات النسخة 84 — استوديو الأبحاث الجامعية ومشاريع التخرج، منسّق المراجع الأكاديمية (APA/IEEE)، ومحاكي المقابلات الوظيفية والمنح

## 1. إطلاق «🔬 استوديو الأبحاث الجامعية ومشاريع التخرج والتوثيق والمقابلات» (`#uniResearchCareerStudio` و `js/unicareer.js`)
- **أولاً — مساعد الأبحاث الجامعية ومشاريع التخرج (عربي + `English Abstract`):**
  - يولّد خطة ومقترح بحث جامعي أو مشروع تخرج متكامل يشمل: العنوان بالعربية والإنجليزية، الملخص الأكاديمي العربي، والملخص الإنجليزي (`Abstract in English`)، ومشكلة الدراسة وأسئلتها، والأهداف، والمنهجية، وهيكل الفصول الخمسة.
  - يتصل مباشرة بـ **قارئ الكتب التفاعلي** و**قاعدة بيانات الـ Markdown** لاستيراد موضوع البحث أو الفقرات المقتبسة بضغطة زر، مع تصدير بصيغة `Markdown (.md)` إلى قاعدة بيانات الموقع أو طباعة `PDF`.
- **ثانياً — منسّق التوثيق والمراجع العلمية القياسي (`APA 7th / IEEE / Harvard / MLA`):**
  - استيراد بيانات أي كتاب مسجل في قاعدة بيانات الموقع أو القارئ التفاعلي بنقرة واحدة، وتوليد التوثيق القياسي **داخل المتن (`In-Text Citation`)** و**في قائمة المراجع النهائية (`Bibliography`)** مع حفظ قائمة مراجع البحث ونسخها كاملة.
- **ثالثاً — محاكي ومدرب المقابلات الوظيفية والمنح الجامعية (`Job & Scholarship Interview Simulator` بالعربية والإنجليزية):**
  - يضم 4 مسارات مقابلات (الوظائف التقنية والهندسية، الوظائف التعليمية والتربوية، مقابلات المنح الجامعية والدراسات العليا، والأسئلة السلوكية والقيادية `HR`).
  - يعرض السؤال بالعربية والإنجليزية، الهدف الخفي للجنة المقابلة، والإجابة النموذجية المزدوجة وفق منهجية `STAR`، مع إمكانية استيراد بيانات السيرة الذاتية من `#cvBuilderStudio` وتقييم إجابة المتدرب لحظياً.
