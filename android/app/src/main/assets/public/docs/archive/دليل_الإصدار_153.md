# دليل الإصدار 153 الشامل — أيقونة أعمالي الحرة والقابلة للإخفاء + حزمة الميزات المتكاملة

## 1) 📂 أيقونة «أعمالي» الحرة على الشاشة مع إمكانية الإخفاء والإظهار (`js/export.js` + `js/assistant.js`)
- **تحريك حر على الجوال والكمبيوتر:** اسحب أيقونة «أعمالي» (`#exFab`) بإصبعك لأي مكان يناسبك على الشاشة، وتُحفظ إحداثياتها تلقائياً مع التكيّف مع أبعاد الشاشة.
- **إخفاء وإظهار بضغطة واحدة:** يمكنك إخفاء الأيقونة مباشرة عبر زر `✕` الصغير فوقها أو من داخل نافذة أعمالي (`👁️‍🗨️ إخفاء الأيقونة`)، وإعادة إظهارها في أي وقت من قائمة إعدادات «مساعدي» (`⚙️ ← 📂 إظهار/إخفاء أيقونة أعمالي`).

## 2) 🌐 تصدير الاختبار والملخص التفاعلي كملف HTML يعمل بلا إنترنت
- زر **«🌐 HTML»** أسفل كل رد في المحادثة ينتج ملف HTML واحد خفيف ومنسّق بالعربية يتضمن بطاقة تحقق فوري من الفهم، يرسله المعلم لطلابه عبر واتساب أو تليجرام ليفتحوه على هواتفهم بدون إنترنت.

## 3) 🎥 تسجيل وتنزيل فيديو ريلز 9:16 فعلياً + ✏️ لوحة الرسم اليدوي للمعادلات
- **تصدير فيديو ريلز (`.webm`):** زر **«🎥 تصدير فيديو (.webm)»** داخل نافذة ريلز 9:16 يرسم الشرائح العمودية ويسجلها تلقائياً كملف فيديو جاهز للنشر.
- **لوحة الرسم والكتابة اليدوية (`✏️`):** زر بجانب الكاميرا في شريط المحادثة يفتح لوحة رسم باليد مع رموز رياضية سريعة (`√, π, ∑, ∫, ², ÷, ×`) لإرفاق المعادلات والأشكال الهندسية وحلها فوراً.

## 4) 👨‍🏫 وضع المساعد الصفي + 🩺 بنك أخطائي + 📆 عدّاد الامتحانات المتعدد + ⭐ نقاط XP + 👁️ وضع القراءة الدافئة
- **المساعد الصفي (`⚙️ ← 👨‍🏫 وضع المساعد الصفي`):** سحب اسم طالب عشوائياً مع عدّاد 15 ثانية ناطق.
- **بنك أخطائي (`⚙️ ← 🩺 بنك أخطائي PDF علاجي`):** يرصد الأخطاء في التسميع السقراطي ويولّد ملف PDF علاجياً مخصصاً.
- **قوالب PDF جديدة:** المقارنة البصرية (`⚖️`)، الإذاعة المدرسية (`🎙️`)، القصة الحوارية (`📖`)، رسائل أولياء الأمور (`✉️`)، والبطاقة ثنائية اللغة (`🌍 AR/EN`).
- **الربط المباشر بتليجرام (`📢 تليجرام`)** و**وضع القراءة الدافئة وتكبير الخط (`👁️`)** و**نظام النقاط والأوسمة (`XP`)**.
