# الإصدار 148 — «مساعدي» + أداء أسرع

## الجديد
- **مساعدي** (الزر العائم أسفل اليسار أو Alt+A): دردشة ذكية، مهام وملاحظات، مؤقت تركيز (بومودورو)، عادات يومية بسلاسل أيام، إملاء صوتي، بحث وفتح أي أداة بالكلام (مثل «افتح ورقة عمل»)، تصدير/استيراد بياناتك من قائمة ⋯.
  - أوامر سريعة: «احسب 15×8+3»، «ركّز 25 دقيقة»، «ذكّرني بمراجعة الكسور»، «دوّن ...»، «امتحان بعد 10 أيام».
  - بيانات المساعد محفوظة على جهازك لكل حساب؛ استخدم التصدير للنقل بين الأجهزة.
- **الأداء**: خط Cairo فقط عند الإقلاع (باقي الخطوط عند اختيارها)، كاش ذكي (stale-while-revalidate) في sw.js، ترويسات كاش لملفات js.
- **الثبات**: إصلاح أخطاء الإقلاع عند تعذّر تحميل Firebase (بدائل آمنة في cloud.js).
- **الصلاحيات**: يبقى نظام 147 (سياسات + منح فردية + طلبات وصول) كما هو.

## خطوة مهمة لسرعة أكبر (مرة واحدة)
استبدال Tailwind CDN بملف CSS جاهز:
```
cd tools/tailwind-build
npm install
npm run build
npm run apply
```
(للتراجع: `node apply.js --undo`). التفاصيل في tools/tailwind-build/README.md.
