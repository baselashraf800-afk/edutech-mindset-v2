# تطويرات النسخة 87 — استوديو الخرائط المفاهيمية والمخططات الانسيابية التفاعلية + محاكي قاعة الامتحان الرسمي بالعد التنازلي

## 1. إطلاق «🗺️ استوديو الخرائط المفاهيمية التفاعلية ومحاكي قاعة الامتحان الموقوت» (`#visualConceptExamStudio` و `js/visualconcept.js`)
- **أولاً — راسم الخرائط المفاهيمية والمخططات الانسيابية التفاعلي (`Interactive Concept Map & Flowchart Studio`):**
  - يستخرج تلقائياً من أي فصل أو كتاب في قاعدة بيانات الـ Markdown خريطة مفاهيمية بصرية بـ 3 أنماط عرض:
    1. **🌳 خريطة شجرية هرمية (`Tree Concept Map`).**
    2. **🔄 مخطط انسيابي متسلسل للخطوات والقوانين (`Sequential Flowchart`).**
    3. **🎯 شبكة مفاهيمية (`Concept Cards Grid`).**
  - يدعم إضافة عقد فرعية جديدة، وحفظ الخريطة المفاهيمية بصيغة `Markdown (.md)` مباشرة داخل قاعدة بيانات الموقع.
- **ثانياً — محاكي قاعة الامتحان الرسمي بالعد التنازلي (`Timed Official Exam Hall Simulator`):**
  - يبني جلسة امتحان موقوتة (10 دقائق بالعد التنازلي الحي) من فصول الكتب المسجلة في الموقع.
  - يضم لوحة أرقام الأسئلة للتنقل السريع، وميزة **«🚩 علّم للمراجعة لاحقاً»**، وعند تسليم الامتحان يصدر **تقريراً تشخيصياً مفصلاً** يوضح الدرجة والنسبة المئوية والتفسير المنهجي لكل سؤال مع زر إرسال الأسئلة مباشرة إلى **«المراجعة الذكية بالتكرار المتباعد»**.
