# دليل التطويرات الجديدة — الإصدار 93 (EduTech Mindset v93)

1. **محرك قراءة المناهج متعدد الصفحات الفعلي (`Real Page-by-Page Curriculum Textbook Engine`)**:
   - عند تقليب الصفحات (`الصفحة التالية ▶` أو `◀ الصفحة السابقة` أو اختيار رقم الصفحة)، يتغير محتوى الصفحة بالكامل ليعرض النص القرائي الفعلي الخاص بتلك الصفحة:
     - **صفحة التمهيد والشرح الأساسي**
     - **صفحة تفصيل المفاهيم والتحليل**
     - **صفحة الأمثلة المحلولة والنشاط التعاوني**
     - **صفحة التطبيقات العملية والمقارنات وربط البيئة الفلسطينية**
     - **صفحة أسئلة المراجعة والتقويم مع الحلول النموذجية**
2. **شريط تصفح سريع لصفحات الوحدة + مزامنة تلقائية بين رقم الصفحة والوحدة الدراسية**.
3. **تنظيف الشريط السفلي للهاتف (`#mobileBottomNav`) من زر «مصادري» العام** واستبداله بأزرار تصفح المراحل وقراءة الكتاب والمكتبة والجامعة.
