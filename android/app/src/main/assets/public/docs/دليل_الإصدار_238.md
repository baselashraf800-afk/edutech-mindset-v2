# دليل الإصدار 238 — إعادة تصميم بوابة الأدوات ومنظومة الموشن جرافيك الحيوية (60fps)

## أبرز ما تم إنجازه في الإصدار 238
| المحور | التطوير المنفّذ |
|---|---|
| إصلاح وإعادة تصميم بوابة الأدوات | حل مشكلة النص الأبيض على خلفية بيضاء نهائياً باستخدام CSS صريح عالي التباين في الوضعين الفاتح والداكن، وتصميم شبكة تطبيقات حديثة (بطاقتان بالصف على الجوال و3–4 على الكمبيوتر) بهوية لونية مبهجة لكل فئة (طالب / معلم / ذكاء ومختبرات / مفضلة) |
| موشن جرافيك حيوي للموقع بالكامل (`css/motion-v238.css`) | إضافة خلفية شفق حيّة متفائلة (سماوي + زمردي + ذهبي)، وحركة دخول سينمائية متتابعة عند التمرير (`IntersectionObserver`)، ولمعة ضوئية ناعمة على الأزرار الرئيسية، وارتداد مرن عند اللمس — بتسريع GPU فقط بلا أي ثقل |
