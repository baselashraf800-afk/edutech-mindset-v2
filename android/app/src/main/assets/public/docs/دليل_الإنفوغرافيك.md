# مولّد الإنفوغرافيك والبوسترات

1) **انشر قواعد Firestore المحدّثة** (ملف firestore.rules): فيها قاعدة `designs`، وتصاميم كل معلم خاصة به.
2) القسم يظهر بعد «مولّد خطط الدروس»، ويمكن إخفاؤه أو نقله من تخصيص الموقع ← الأقسام.
3) اختر النوع (بوستر إعلان / لوحة تعليمية / بطاقة إنجاز) والمقاس (A4 / مربع / ستوري)، واكتب وصفاً بجملة. يكتب الذكاء الاصطناعي النص، وتعدّله ثم تغيّر القالب (6 قوالب) وتضيف صورة دائرية (شعار أو صورة طالب).
4) **PNG:** يُنشأ داخل المتصفح بدون مكتبات، ويستخدم خطوط جهازك العربية (قد يختلف شكل الخط قليلاً عن المعاينة). **PDF:** عبر نافذة الطباعة، ومقاسه يطابق المقاس المختار.
5) لا يخترع الذكاء الاصطناعي تواريخ أو أرقام تواصل: يضع ما كتبته في الوصف فقط. راجع النص قبل النشر.
